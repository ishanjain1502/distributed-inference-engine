Which Stats page layout?

Click A, B, or C. Same data either way — cluster summary + per-worker + per-session rows.

A

Stacked workers (expandable)

Cluster strip on top. Each worker is a row you expand to see its sessions table.

B

Master–detail

Workers list on the left; selecting one fills the right panel with that worker’s sessions.

C

Flat session table

Cluster strip + one big table of all sessions (worker as a column). Simpler, less hierarchy.
